# 🟡 ShadowFox Data Science Internship – Intermediate Task

## Delhi Air Quality Index (AQI) Analysis

This project is part of the **ShadowFox Data Science Internship – Intermediate Level**.

The task focuses on conducting an in-depth analysis of the **Air Quality Index (AQI) in Delhi** using Python and data analysis and visualization techniques.

The objective is to explore air-quality data, understand pollution patterns, analyze changes in AQI and pollutants, and present meaningful insights through data visualization.

---

## 📌 Objective

The main objective of this project is to analyze Delhi's air quality data and identify important patterns and trends in pollution levels.

The analysis focuses on:

- Understanding Delhi's AQI data
- Exploring air pollution levels
- Analyzing pollutant concentrations
- Studying AQI variations over time
- Identifying patterns and trends
- Creating meaningful visualizations
- Extracting data-driven insights

---

## 📊 Dataset

The project uses the **Delhi AQI dataset provided for the ShadowFox internship task**.

The dataset contains air-quality observations that can be explored to understand AQI levels and pollutant behavior over time.

The analysis is performed using Python-based data analysis and visualization tools.

---

## 🔍 Data Analysis

The project includes the following stages:

### 1. Data Loading

- Importing the dataset
- Loading the data using Pandas
- Examining the available columns and records

### 2. Data Understanding

- Checking dataset dimensions
- Examining data types
- Inspecting the first and last records
- Understanding the AQI and pollutant-related variables
- Identifying missing values

### 3. Data Cleaning

The dataset is prepared for analysis by:

- Checking missing values
- Handling inconsistent data
- Checking duplicate records
- Converting columns to appropriate data types where required
- Preparing time-related columns for analysis

### 4. Exploratory Data Analysis

The analysis explores:

- AQI levels
- Pollutant concentrations
- Changes in AQI over time
- Daily pollution patterns
- Relationships between AQI and pollutants
- Distribution of air-quality measurements

---

## 🌫️ Key Pollutants

The analysis considers important air pollutants available in the dataset, such as:

- PM2.5
- PM10
- NO₂
- CO
- SO₂
- O₃

The available columns depend on the provided dataset.

## 📈 Data Visualization

Visualizations are created to understand and communicate air-quality patterns.

Examples include:

- Line charts
- Bar charts
- Histograms
- Scatter plots
- Box plots
- Heatmaps

These visualizations help identify changes, distributions, relationships, and trends within the AQI data.

## 🔎 Research Areas

The project investigates areas such as:
