# 🟢 ShadowFox Beginner Task

## Python Visualization Libraries Documentation

This project is part of the **ShadowFox Data Science Internship – Beginner Level**.

The task focuses on creating a comprehensive documentation guide for two Python visualization libraries:

- Matplotlib
- Seaborn

- Advantages and limitations

- Performance with large datasets
